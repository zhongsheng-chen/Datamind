# 部署与运行

部署（`Deployment`）将一个模型版本发布到指定环境，记录发布方式、角色与期望状态。运行实例（`Runtime`）记录节点的加载与执行状态。两者共同描述一次发布：部署表示平台希望运行什么，运行实例表示节点实际运行了什么。

## 激活、启用与加载

注册只保存模型制品。激活版本后可以创建部署；启用部署后，预测服务开始协调模型加载。部署处于启用状态时，模型可能仍在加载，也可能加载失败。

因此，发布后需要同时确认部署状态与运行实例状态，再接入流量。停用部署后也要等待实际卸载，才能继续清理版本或制品。运行状态字段见[状态与权限](../reference/states-permissions.md)。

## 发布方式与角色

| 发布方式（`rollout_type`） | 用途 | 角色（`role`） |
| --- | --- | --- |
| `full` | 单一正式版本提供预测 | 自动使用 `champion` |
| `canary` | 新旧版本共同服务，逐步放量 | 创建时选择 `champion` 或 `challenger` |
| `shadow` | 使用真实输入旁路验证候选版本 | 自动使用 `shadow` |

角色说明部署的用途，流量比例由路由配置。启用候选部署并不等于候选版本已经获得流量。普通路由、实验分组或定向请求决定哪个部署执行主预测；影子路由决定旁路执行目标，详见[流量分配](../routing/index.md)。

## 服务与运行实例

预测服务执行在线预测，任务 Worker 执行批量和影子任务，管理控制台提供操作界面。这些进程需要访问同一数据库与制品存储，才能协调部署并加载相同版本。

运行实例是平台记录的节点状态，预测服务是承载运行与请求处理的进程。启动进程见[服务管理](processes.md)，共享存储与故障处理见[生产部署](production.md)。

首次发布从[全量部署](full.md)开始。更新已有服务时选择[金丝雀发布](canary.md)或[影子预测](shadow.md)。
